Chapter 05.4 · Python

A zero-runtime-dependency Python client.

The synchronous Python 3.10+ package uses the standard library for HTTP, immutable values for composition, and strings for every arbitrary-precision result.

Install

python -m venv .venv
source .venv/bin/activate
python -m pip install ./python-api

On Windows PowerShell, activate with .venv\Scripts\Activate.ps1. The distribution is nologo-math2 and the import package is nologo_math2.

Compose and calculate

from nologo_math2 import Equation, Math2Client, Number

client = Math2Client()
two = Equation.of(Number.from_integer(2))
three = Equation.of(Number.from_integer(3))
equation = three.sqrt().add(two.power(three))
result = client.calculate(equation, precision=100)
print(result)

Ordered batches

equations = (
    Equation.parse("1+1"),
    Equation.parse("max(2,3)"),
    Equation.parse("sqrt(16)"),
)
results = client.calculate_batch(equations, precision=1000)
assert tuple(map(str, results)) == ("2", "3", "4")

Batch results are returned as an immutable tuple with the request's order and cardinality.

Configuration and errors

client = Math2Client(
    base_url="https://math2.example.test",
    timeout_seconds=30,
)

ValidationError, TransportError, ProtocolError, and ServiceError keep local input, network, malformed-response, and structured HTTP failures distinct. A service error retains status, code, and optional position.
