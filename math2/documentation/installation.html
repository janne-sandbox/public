macOS

The fastest path on macOS is Homebrew. Install Homebrew first if you do not have it, then install the tools you need.

Java 21 and Maven

brew install openjdk@21 maven

# Homebrew may require this symlink for the system Java wrapper:
sudo ln -sfn $(brew --prefix)/opt/openjdk@21/libexec/openjdk.jdk \
    /Library/Java/JavaVirtualMachines/openjdk-21.jdk

Alternative: SDKMAN! lets you manage multiple JDK versions side by side:

curl -s "https://get.sdkman.io" | bash
sdk install java 21.0.7-tem   # Eclipse Temurin build
sdk install maven

C++ (cpp-api)

xcode-select --install   # installs Apple Clang
brew install cmake

Rust (rust-api)

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
# follow the on-screen prompts; reload your shell or run:
source "$HOME/.cargo/env"

.NET 8 (dotnet-api)

brew install dotnet@8
# Add the SDK to your PATH (add this line to ~/.zshrc or ~/.bash_profile):
export PATH="/opt/homebrew/opt/dotnet@8/bin:$PATH"

Alternative: download the macOS installer from dotnet.microsoft.com.

Node.js / npm (js-api, ts-api)

brew install node   # includes npm

Build from source

After installing the prerequisites, build the components you need with build-all.sh.

# Build everything (Java library, REST service, and all clients)
./build-all.sh

# Build specific targets
./build-all.sh java-api              # Java library only
./build-all.sh java                  # Java library + REST service
./build-all.sh java cpp-api          # Java modules and C++ client
./build-all.sh rust-api dotnet-api   # two clients

# Show available targets
./build-all.sh --help

Missing toolchains are skipped with a notice rather than failing the entire build. Java is the only required component.

Bind address and port

The REST service listens on 127.0.0.1:8080 by default. 127.0.0.1 is the loopback address — connections are only accepted from the same machine. No other host on the network can reach the service unless you explicitly change this.

Why loopback by default? Binding to loopback means the service is unreachable over the network without additional configuration. This limits the attack surface: authentication, TLS, and rate limiting belong at a reverse proxy or API gateway placed in front of Math2, not inside the service itself.

Changing the address and port

Pass environment variables before the JAR or export them before running run-dev-local.sh:

# Accept connections from any network interface on port 9090:
MATH2_SERVER_ADDRESS=0.0.0.0 MATH2_SERVER_PORT=9090 java -jar math2-rest-service-*.jar

# Bind to a specific interface only (e.g. a private LAN address):
MATH2_SERVER_ADDRESS=192.168.1.10 java -jar math2-rest-service-*.jar

The same variables work as Docker -e flags:

docker run --rm \
  -e MATH2_SERVER_ADDRESS=0.0.0.0 \
  -e MATH2_SERVER_PORT=9090 \
  -p 9090:9090 \
  math2:local

Alternatively, create an application.properties file next to the JAR:

server.address=0.0.0.0
server.port=9090
Security note. Binding to 0.0.0.0 exposes the service on every network interface, including public ones. Add a reverse proxy (nginx, Caddy, Traefik) with TLS and authentication in front of Math2 before exposing it beyond the local machine.

Swagger UI

The running service exposes an interactive API browser powered by Swagger UI and generated from the OpenAPI 3 specification embedded in the service.

# Start the service, then open in a browser:
http://127.0.0.1:8080/swagger-ui.html

From Swagger UI you can:

  • Browse every endpoint with its parameter descriptions and response schemas.
  • Enter an equation and precision directly in the browser and execute the call — no curl or client code needed.
  • Copy the curl command that Swagger generates to reproduce the request from a terminal.
  • Inspect the exact JSON response format and error shapes.

The raw OpenAPI specification is available as JSON:

http://127.0.0.1:8080/v3/api-docs

Import that URL into Postman, Insomnia, or any tool that understands OpenAPI 3 to generate a ready-to-use client collection.

H2 console. The embedded H2 database management console is disabled. Manage the calculation cache through the application endpoints only.
