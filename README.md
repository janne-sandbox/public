# public

Public sandbox projects for experimentation and reference implementations.

## Projects

### [Math2](math2/)

An arbitrary-precision decimal calculation toolkit. Includes a standalone Java JAR, a Spring Boot REST service with a persistent bounded cache, and client libraries for JavaScript, TypeScript, C#, C++, and Rust.

[Documentation](https://janne-sandbox.github.io/public/math2/documentation/)

### [Example](example/)

A requirements-driven code review agent suite supporting TypeScript, Java, Rust, React, C/C++, and C#. Combines deterministic pattern checks with optional Deepseek analysis and produces Markdown reports per run.

[Documentation](https://janne-sandbox.github.io/public/example/documentation/)
